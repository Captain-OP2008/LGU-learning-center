## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。
所有章节、代码运行、练习题都在本地文件里，不需要联网、不需要装 Java。

**方法 2（推荐，可离线安装）**：在本文件夹里起一个静态服务器，浏览器访问 `http://127.0.0.1:8788`：

```powershell
# 方法 A：装了 Python 3 的话
python -m http.server 8788

# 方法 B：没装 Python（Windows 常见）——用站点自带的零依赖服务器
node _dev/serve.js 8788
```

> `_dev/serve.js` 只用 Node 内置模块，不需要 `npm install`。两条命令都要在**本文件夹内**执行。

用 http 打开后，站点会注册 Service Worker——第一次加载完，**断网也能继续学**，
还可以在浏览器里"安装到桌面"，像 App 一样用。

> 首页左上角的徽标可以随时点回初始页（世界星图入口）。

### 首页世界星图（WORLD CHART）

首页是一张横向的「课程世界星图」：**左侧核心恒星 = 课程核心，向右按 8 个 Part 分成 8 个星区，沿轴排列 26 颗行星 = 26 个章节**；每颗行星下方垂下一串入口节点。

- **天体数据可视化**：行星直径 ∝ 课时（22–48 min → 34–66px）；环星 / 气态巨行星 / 冰巨星自带环；行星纹理是 10 种程序化世界风格（岩质、海洋、沙漠、冰、极光、气态、环星、风暴、熔岩、冰巨星），按章节主题固定映射；行星大气辉光使用所属 Part 的四色

## 四、想自己改内容？

正文是**数据驱动**的：每章一个 `data/chXX.js`，文件结构如下（完整字段见 `_dev/CONTRACT.md`）：

```js
CSC.registerChapter({
  id: 'ch03', num: '03', title: '条件与循环', en: 'Conditionals & Loops',
  goals: ['……'],                       // 学习目标
  kp: [{ id:'ch03-1', title:'if 语句' }], // 知识点
  blocks: [                            // 内容块，按顺序渲染
    { t: 'p', html: '一段正文，可以用 <code>行内代码</code> 和 <b>加粗</b>' },
    { t: 'code', caption: 'Demo.java', code: 'public class Demo { ... }' },
    { t: 'lab', id: 'loops' },
    { t: 'quiz', qid: 'ch03-q1' },
    { t: 'checklist', id: 'ch03', items: ['我能……'] }
  ]
});
```

支持的块类型：`h p callout code codegroup table term terms lab quiz steps compare memory flow svg grid tabs checklist keypoint divider`。

改完直接刷新浏览器即可（http 方式下建议 Ctrl+F5 强刷）。

- **改配色 / 字号 / 线宽**：改 `../../shared/css/observatory.css` 顶部 `html[data-theme="dark"]` 里的 CSS 变量即可，六站统一生效。
- **改页面布局**：外壳与首页在 `../../shared/css/observatory.css`（`02 外壳` / `04 首页世界星图` / `05 章节阅读`），其余页面在 `../../shared/css/pages-*.css`；本站单独的参考页外观才在 `assets/pages-reference.css`。
- **改视觉组件参数**（等高线密度、启动文案时长）：调用 `CSC_OBS.mountTopo / mountBoot` 时传参，见 `assets/observatory.js` 文件头注释。

## 五、技术说明

- **无构建、无依赖、无 CDN**：全部原生 JS / CSS / SVG，字体由 `../../shared/fonts` 本地提供，离线可用。
- **自研 Java 子集解释器**（`assets/engine.js`）：手写词法分析 → 递归下降语法分析 → AST 树遍历执行（generator 实现单步）；`assets/editor.js` 是编辑器与调试面板。
- **单步执行**：语句级快照（当前行 / 调用栈帧 / 局部变量 / 堆对象 / 引用关系 / 输出），用于"内存图"可视化。
- **程序化视觉**：等高线地形由梯度噪声 + marching squares 生成（无贴图）；启动终端、打字机、四色幕布、四色色标均由 CSS/JS 实现。
- **安全**：不使用 `eval`/`new Function` 执行代码，全部通过 AST 解释；死循环有步数（100 万步）与时间（2 秒）上限；递归深度上限 1000（宿主 JS 引擎栈实际约 500–600 层就会抛 `StackOverflowError`）。
- **兼容**：Chrome / Edge / Firefox / Safari 近两年版本；桌面与移动端自适应（<900px 世界星图改纵向模块索引、侧栏变抽屉）；支持 `prefers-reduced-motion` 降级与打印。

### 解释器支持的 Java 范围

| 类别 | 支持 |
| --- | --- |
| 字面量与运算 | 全部基本字面量、转义序列、十六/二/八进制、下划线分隔、后缀；全部算术/关系/逻辑/位/赋值/三元运算符 |
| 语句 | 变量声明（含 `final`）、`if/else`、`while`、`do-while`、`for`、增强 `for`、`break/continue`（含标签）、`switch`、`return`、代码块 |
| 类型 | `int`（32 位回绕）、`long`、`double`、`float`、`char`、`boolean`、`byte`、`short`、`String`，隐式提升、强制转换 |
| 字符串 | `+` 拼接与常用方法（`length/charAt/substring/indexOf/equals/toUpperCase/trim/split/replace/...`）、`String.valueOf/format/join` |
| 数组 | `new`、数组字面量 `{...}`、多维数组、`length`、越界异常、默认值、别名、对象数组 |
| 面向对象 | `class`/`interface`/`abstract class`、字段、构造器与方法重载、`this`/`super`、方法重写、动态派发、`instanceof`、向上转型、`toString` 自动调用、`static` |
| 内置库 | `Math`、包装类、`Arrays`、`System.arraycopy`、`ArrayList`/`HashMap`/`HashSet`、`Collections`、`Scanner`、`printf`/`String.format`（宽度/对齐/补零/精度） |
| 异常 | 数组越界、空指针、除零、字符串越界、负数组长度、类型转换、栈溢出、数字格式、输入不匹配——消息仿真实 JVM，带行号与中文提示 |

**不支持**：`try/catch/throw`、自定义异常类、`enum`、内部类/匿名内部类、lambda/方法引用、泛型类型检查（仅语法忽略）、自动装箱（`Object o = 5`）、多文件/`package`、文本块 `"""`、正则语义。

其他已知差异：

- 类型检查是"执行到才检查"，永不执行的分支里的类型错误不会报出；
- `long` 超过 2^53 会丢精度（JS 数字）；
- `float` 没有真正的 32 位精度（内部按 double 算，`0.1f+0.2f` 不会得到 `0.3`）；
- 字符串常量折叠的 `==` 角落场景（`"abc" == "ab" + "c"`）与 javac 略有差异；
- `StringBuilder`、接口常量（`interface` 里的 `static final` 字段）、`getClass()`、可变参数传数组、包装类自动装箱/`valueOf` 语义等少数写法未实现；
- 3 处 javac 会拒绝但本站照跑：`static` 方法里调实例方法、`printf("%d", 3.5)`、`switch(null)`；
- 字符串越界与空指针的报错文案仍是 Java 8 风格（JDK 13+ 措辞不同）；
- 父类构造器里调用被子类重写的方法时，子类字段的初始化时机与真实 JVM 不同（JVM 中此时子类字段尚未初始化，本站引擎已初始化）——站内示例已避开该写法，考试若考"构造器里调可重写方法"的陷阱请以课堂/JVM 行为为准。

> 这些差异都不影响 本课程的课程语法与考试范围。展示用的代码已全部用真实 JDK 编译运行过，
> 输出与解释器逐字节一致（96 段代码块中 89 段完全一致，其余为 `args` 回放差异、随机数与故意报错示例）。

## 六、已知限制

1. 解释器覆盖的是**课程语法子集**，不是完整 JDK（见上表）。绘图章节（`StdDraw`）的真实代码仍不在站内执行，但交互实验室里有 **StdDraw 绘图台**：用 Canvas 重绘同一套图元，可视化递归树 / 科赫雪花 / 随机漫步，并附真实 algs4 源码对照。
2. 单步粒度是**语句级**，不是表达式级；循环每轮停一次。
3. **模拟卷是练习性质的自动判分**：选择/判断/填空/读代码写输出按标准答案判，简答与找 bug 题按关键词命中比例给部分分，与真实人工阅卷会有出入——成绩页会同时展示参考答案，请以自评为准。
4. 成绩记录（答题对错与模拟卷成绩）只存在本地浏览器（`csc.java.*`），不跨设备同步。
5. 内容是个人学习用途整理，非官方教学材料；与课程要求冲突时以老师和课程大纲为准。
6. **桌面端默认 115% 缩放**（v1.7.0 起）：主内容区（顶栏、正文、右栏、首页星图）按等效浏览器 115% 页面缩放渲染，侧栏保持原尺寸；窗口宽度 ≤900px（手机/平板竖屏）与打印时自动回到 100%。网页无法修改浏览器的原生缩放设置——如果你在浏览器里另外按了 Ctrl+加号，两者会叠加；想恢复原始大小按 Ctrl+0 即可。
