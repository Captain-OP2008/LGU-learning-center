## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。
所有章节、练习题、实验台都在本地文件里，不需要联网、不需要装 Java。

**方法 2（推荐，可离线安装）**：在本文件夹里起一个静态服务器，浏览器访问 `http://127.0.0.1:8788`：

```powershell
# 装了 Python 3 的话
python -m http.server 8788
```

> 如果本文件夹还在「学习中心」里，也可以在学习中心根目录运行仓库自带的零依赖服务器（`node _serve.js`，默认 8811 端口），再访问 `/sites/csc1004/`。

用 http 打开后，站点会注册 Service Worker —— 第一次加载完，**断网也能继续学**，
还可以在浏览器里"安装到桌面"，像 App 一样用。

> 首页左上角的徽标可以随时点回初始页（世界星图入口）。

### 首页世界星图（WORLD CHART）

首页是一张横向的「课程世界星图」：**左侧核心恒星 = 课程核心，向右按 7 个 Part 分成 7 个星区，沿轴排列 21 颗行星 = 21 章**；每颗行星下方垂下一串入口节点。

## 四、想自己改内容？

正文是**数据驱动**的：每章一个 `data/chXX.js`，结构如下：

```js
CSC.registerChapter({
  id: 'ch04', num: '04', title: '继承、多态与接口', en: 'Inheritance, Polymorphism & Interfaces',
  goals: ['……'],                          // 学习目标
  kp: [{ id:'ch04-1', title:'继承与 IS-A' }], // 知识点
  blocks: [                               // 内容块，按顺序渲染
    { t: 'p', html: '一段正文，可以用 <code>行内代码</code> 和 <b>加粗</b>' },
    { t: 'code', caption: 'Demo.java', lang: 'java', code: 'public class Demo { ... }', run: false },
    { t: 'lab', id: 'inherit' },
    { t: 'quiz', qid: 'ch04-q1' },
    { t: 'checklist', id: 'ch04', items: ['我能……'] }   // 勾选只在本次会话内，不写入本地存储
  ]
});
```

支持的块类型：`h p callout code codegroup table term terms lab quiz steps compare memory flow svg grid tabs checklist keypoint divider`。

改完直接刷新浏览器即可（http 方式下建议 Ctrl+F5 强刷）。

- **改配色 / 字号 / 线宽**：改 `assets/observatory.css` 顶部 `html[data-theme="dark"]` 里的 CSS 变量即可，全站生效。
- **改页面布局**：外壳与首页在 `assets/observatory.css`，其余页面在 `assets/pages-*.css`。
- **改实验台**：`assets/labs.js`（Java 部分）与 `assets/labs2.js`（Python 部分），都用 `CSC.registerLabs({...})` 注册。

## 五、技术说明（重要：解释器的边界）

- **无构建、无依赖、无 CDN**：全部原生 JS / CSS / SVG，字体本地打包，离线可用。
- **自研 Java 子集解释器**（`assets/engine.js`）：手写词法分析 → 递归下降语法分析 → AST 树遍历执行（generator 实现单步）。
  **它只覆盖课程 ch01–ch04 的语法范围**，用于"改代码看结果"和"逐行看变量"；从 ch05 起代码块为静态展示。
- **单步执行**：语句级快照（当前行 / 调用栈帧 / 局部变量 / 堆对象 / 引用关系 / 输出）。
- **程序化视觉**：等高线地形由梯度噪声 + marching squares 生成（无贴图）。
- **安全**：不使用 `eval`/`new Function` 执行代码，全部通过 AST 解释；死循环有步数与时间上限。
- **兼容**：Chrome / Edge / Firefox / Safari 近两年版本；桌面与移动端自适应（<900px 世界星图改纵向索引）；支持 `prefers-reduced-motion` 降级与打印。

### 解释器支持的 Java 范围

| 类别 | 支持 |
| --- | --- |
| 字面量与运算 | 全部基本字面量、转义序列、十六/二/八进制、全部算术/关系/逻辑/位/赋值/三元运算符 |
| 语句 | 变量声明（含 `final`）、`if/else`、`while`、`do-while`、`for`、增强 `for`、`break/continue`、`switch`、`return`、代码块 |
| 类型 | `int`/`long`/`double`/`float`/`char`/`boolean`/`byte`/`short`/`String`，隐式提升、强制转换 |
| 字符串 | `+` 拼接与常用方法（`length/charAt/substring/indexOf/equals/toUpperCase/trim/split/replace/...`） |
| 数组 | `new`、数组字面量、多维数组、`length`、越界异常、别名、对象数组 |
| 面向对象 | `class`/`interface`/`abstract class`、字段、构造器与方法重载、`this`/`super`、重写、动态派发、`instanceof`、向上转型、`toString`、`static` |
| 内置库 | `Math`、包装类、`Arrays`、`ArrayList`/`HashMap`/`HashSet`、`Scanner`、`printf`/`String.format` |

### **不支持**（这正是本站 ch06 之后代码只展示的原因）

| 课程主题 | 为什么不能在站内跑 | 站内怎么讲 |
| --- | --- | --- |
| Socket / ServerSocket | 浏览器没有 TCP 客户端能力 | 实验台 `socket`（连接时序 + 消息往返动画） |
| Thread / 多线程 | 浏览器主线程模型不同 | 实验台 `threads`（调度时间线 + 五态状态机） |

| 文件 I/O、`try-catch`、lambda | 引擎未实现 | ch06 讲流包装链（实验台 `streams`）；ch05 讲 lambda 转换（实验台 `lambda`） |
| **Python / Tkinter / PyTorch** | 引擎是 Java 解释器 | 实验台 `pyjava` / `pyclass` / `tkinter` / `snake` / `mlnet` |

## 六、已知限制

1. 解释器覆盖的是**课程 ch01–ch05 语法子集**，不是完整 JDK。从 ch06 起所有代码块为静态展示（`run:false`），
   这是刻意设计——真实项目本来就必须在你的 IntelliJ / PyCharm 里跑。
2. 单步粒度是**语句级**，不是表达式级；循环每轮停一次。
3. **模拟卷是练习性质的自动判分**：选择/判断/填空/读代码按标准答案判，简答与编程题按关键词命中比例给部分分，
   与真实人工阅卷会有出入——成绩页会同时展示参考答案，请以自评为准。
4. 答题对错与模拟卷成绩只存在本地浏览器（`csc.csc1004.*`），不跨设备同步；导出 / 导入功能可手工搬运。
5. 内容是依据公开讲义的个人学习用途整理，非官方教学材料；与课程要求冲突时以老师和课程大纲为准。
6. 项目手册中的代码骨架是**参考实现**，不是唯一正确答案；课程要求每个学生独立完成，请自己写、自己调。
