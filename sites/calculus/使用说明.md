# 微积分学习站 · 使用说明

> **CALCULUS OBSERVATORY** —— 给第一次学微积分的人看的教材。
>
> 内容依据 Thomas' Calculus 14e (SI) 全书，并参照 CUHK-Shenzhen **Calculus I** 的课程范围编排。
> **纯静态、零安装、可离线**，打开就能从第一页读起。
>
> 视觉采用 **NASA-Punk Observatory** 设计语言（参考 flowersauce/NASA-Punk_Observatory，MIT）：
> 深空天文台界面 —— 程序化等高线地形、Jura + Roboto Mono 仪表字体、四色色标、终端读数、四色幕布转场。
> 界面好看是加分项，真正要看的还是每一章里的文字和公式。

## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。
所有章节、公式、实验台、题库都在本地文件里，不需要联网、不需要装任何东西。

**方法 2（推荐，可离线安装）**：在本文件夹里起一个静态服务器，浏览器访问 `http://127.0.0.1:8789`：

```powershell
# 在本文件夹内执行（Python 3；本机用 py 而不是 python）
py -m http.server 8789
```

用 http 打开后，站点会注册 Service Worker——第一次加载完，**断网也能继续学**，
还可以在浏览器里「安装到桌面」，像 App 一样用。

> 首页左上角的徽标可以随时点回初始页（世界星图入口）。
>
> **默认显示比例 115%**：桌面端整站按 115% 显示（正文、读数、公式一起放大，
> 默认阅读更舒服）。想改回原始大小或再放大，编辑 `../../shared/css/observatory.css` 顶部那一行
> `html[data-skin="obs"] { --ui-zoom: 1.15; }`（1.0 = 原样，1.25 = 再大一档）；
> 手机端不使用该缩放（交给浏览器自己的视口）。

## 二、这是一本什么样的教材

一本把 **Thomas' Calculus 14e (SI) 全书**（17 章 + 附录 A + 公式速查）拆成 **20 个学习模块**的
交互式教材，章节顺序与 **Calculus I**（CUHK-Shenzhen，AY2026-27 Term 1，L10，Prof. Ce Ju）大体一致。
每一章都从「这一章要解决什么问题」讲起：先给直觉和例子，再写定义和公式，最后用例题、实验台和练习题把话讲通。

如果只记住一句话：**这里假设你还没学过微积分**。看到看不懂的符号，往回翻或查术语表，不用假装自己已经会了。

| 内容 | 说明 |

| **学习范围徽章** | 每章标出它在课程里的位置：期中范围 / 期末范围 / 先修基础 / 课程外。侧栏与首页星图同步标记 |

### 学习范围徽章怎么用

| 徽章 | 含义 | 范围 |

| 期中范围 | 课程期中之前要覆盖 | §2.1–5.1（第 2–4 章 + 5.1） |
| 期末范围 | 课程期末之前要覆盖 | §5.2–8.8 + §16.1–16.4 |

「课程外」的部分当故事看，能读多少读多少。

### 成绩记录与导出

本站不记录学习进度（没有进度条、没有章节勾选、没有 XP / 等级）。会被保存的只有两类数据：

- **答题记录**：题库里每道题答过几次、对了几次（用于显示「上次答对 / 答错」）
- **模拟卷成绩**：A / B 卷的交卷分数与每套卷的历史记录

两类数据都保存在浏览器的本地存储（localStorage）里，键名以 `csc.calculus.` 为前缀——
六门课各有各的前缀，互不覆盖；数据只留在本机，不上传任何服务器。
换浏览器、清缓存、用无痕模式都会丢失。

在 **关于页 →「导出记录 / 导入记录」** 可以备份或迁移这些成绩：
导出的 JSON 文件名形如 `csc-calculus-records-2026-11-12.json`，只包含答题记录与模拟卷成绩，
不含任何进度数据；导入会覆盖本站现有记录（导入前会二次确认）。关于页还有「清除本站记录」按钮。

## 四、想自己改内容？

正文是**数据驱动**的：每章一个 `data/chXX.js`，文件结构如下（完整字段见文件内各字段注释）：

```js
CSC.registerChapter({
  id: 'ch05', num: '5', title: '积分', en: 'Integrals',
  goals: ['……'],                          // 学完这一章你能做什么
  kp: [{ id:'ch05-1', title:'面积与有限和估算' }], // 知识点
  blocks: [                               // 内容块，按顺序渲染
    { t: 'scope', scope:'both', weeks:'W7–W8', sections:'§5.1–5.6' },  // 学习范围横幅
    { t: 'h', lvl: 2, text: '这一章要解决什么问题' },
    { t: 'list', items: ['一条要点，可以用 <code>行内代码</code> 和 $公式$'] },
    { t: 'tex', tex: '\\int_a^b f(x)\\,dx' },                        // 独立公式纸片
    { t: 'theorem', name: 'FTC Part 2', rows: [{ k:'白话', html:'…' }, { k:'条件', html:'…' }, { k:'结论', html:'…' }, { k:'怎么用', html:'…' }] },
    { t: 'example', no: '1', tag: '跟着做一遍', fields: [{ k:'题目', html:'…' }, { k:'想一想', html:'…' }, { k:'解答', html:'…' }, { k:'点评', html:'…' }] },
    { t: 'lab', id: 'riemann' },
    { t: 'calc', mode: 'integral', title: '定积分演算台' },
    { t: 'quiz', qid: 'ch05-q3' },
    { t: 'checklist', id: 'ch05', items: ['能自己讲出来吗：……'] }
  ]
});
```

支持的块类型：`h p list tex example theorem formula scope callout table term terms lab calc quiz steps compare flow svg grid tabs checklist keypoint divider html`。

改完直接刷新浏览器即可（http 方式下建议 Ctrl+F5 强刷）。

- **改配色 / 字号 / 线宽**：改 `../../shared/css/observatory.css` 顶部 `html[data-theme="dark"]` 里的 CSS 变量即可，全站生效。
- **改页面布局**：外壳与首页在 `../../shared/css/observatory.css`，数学内容在 `assets/math.css`，其余页面在 `../../shared/css/pages-*.css`（六站共享一份，改前留意会影响所有站）。
- **改视觉组件参数**（等高线密度、启动文案时长）：调用 `CSC_OBS.mountTopo / mountBoot` 时传参，见 `assets/observatory.js` 文件头注释。
- **改题库**：`data/quiz.js`，每题 `{ id, ch, type:'mcq', difficulty, tags, scope, stem, options:[{text,correct}], explain }`。

## 五、技术说明

- **无构建、无依赖、无 CDN**：全部原生 JS / CSS / SVG，字体与 MathJax 本地打包，离线可用。
- **公式排版**（`assets/math.js`）：首次进入含公式的章节时按需注入 MathJax，再统一排版，并对每个公式做四层适配——
  ① 过宽行内公式提升为独立「公式纸片」；② 仍放不下按顶层 `=` / `\qquad` 拆成 `aligned` 多行；
  ③ 拆不了（矩阵、分段等）等比缩小（下限 62%，表格内 85%）；④ 表格窄屏转一列卡片。
  缩放后仍超宽的公式与长表格会加上「← 可横向滚动 →」提示与右侧渐隐遮罩，不再无提示地裁切。
- **数据按需加载**：章节正文、题库、模拟卷、实验台、演算台、术语表、公式速查都只在点开对应页面时加载；
  首屏关键路径是 `index.html + data/site.js + CSS + observatory.js + app.js + math.js`；
  2.1 MB 的 MathJax 渲染器不在首屏加载，只在首次进入含公式的章节时注入。
- **程序化视觉**：等高线地形由梯度噪声 + marching squares 生成（无贴图）；启动终端、打字机、四色幕布均由 CSS/JS 实现。
- **安全**：不使用 `eval`/`new Function` 执行内容；公式只经 MathJax 排版。
- **兼容**：Chrome / Edge / Firefox / Safari 近两年版本；桌面与移动端自适应（<900px 世界星图改纵向模块索引）；
  支持 `prefers-reduced-motion` 降级与打印。

### 数学公式排版规则

1. 行内公式超过栏宽约 62% 时，自动变成一张居中「公式纸片」，不再和汉字挤在同一行。
2. 独立公式仍放不下时，按**顶层等号**和 `\qquad` 拆成多行（保持原字号）。
3. 既拆不了又放不下的，等比缩小字号（下限 62%，表格内 85%）。
4. 表格在窄屏（≤700px）自动变成「一列卡片」，每格带表头标签。
5. 缩放后仍超出容器的公式或长表格，会显示「← 可横向滚动 →」提示与右侧渐隐遮罩，可横向拖动查看完整内容。

## 六、已知限制

1. 内容是个人学习用途整理，非官方教学材料；与课程要求冲突时，以老师和课程大纲为准。
2. 解析与模拟卷判分为练习性质：选择题精确匹配，填空题按归一化文本匹配，简答题按关键词命中比例给部分分，
   与真实人工阅卷会有出入——成绩页会同时展示参考答案，请以自评为准。
