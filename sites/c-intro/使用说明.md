# C 语言与系统基础 · 学习站 · 使用说明

> 一门以内存为主线的 C 语言入门课，按「章节 + 示例 + 练习」组织。
> 全站包含：10 章正文、C 速查表、分章题库（90 题）、4 个实战项目、2 套模拟卷。
> **纯静态、零安装、可离线**，双击 `index.html` 就能用。
>
> 视觉语言：NASA-Punk Observatory（深空天文台界面）——程序化等高线地形、Jura + Roboto Mono 仪表字体、四色色标、四色幕布转场。

---

## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。
十个章节、速查表、题库、项目与模拟卷都在本地文件里，不需要联网。

**方法 2（可离线安装）**：在本文件夹里起一个静态服务器：

```powershell
python -m http.server 8788
```

然后访问 `http://127.0.0.1:8788`。用 http 打开后站点会注册 Service Worker，第一次加载完就能断网学习，也可以「安装到桌面」。

> 首页左上角的徽标可以随时点回初始页。

## 四、想自己改内容？

正文是**数据驱动**的：每章一个 `data/chXX.js`，结构如下：

```js
CSC.registerChapter({
  id: 'ch03', num: '03', title: '位运算', en: 'Bitwise Operators',
  goals: ['……'],                          // 学习目标
  kp: [{ id:'ch03-1', title:'按位与 &' }], // 知识点
  blocks: [                               // 内容块，按顺序渲染
    { t: 'p', html: '一段正文，可以用 <code>行内代码</code>' },
    { t: 'code', lang: 'c', caption: 'demo.c', code: 'int main(void){return 0;}' },
    { t: 'table', head: ['A','B'], rows: [['1','2']] },
    { t: 'keypoint', items: [{ title:'要点', html:'……' }] },
    { t: 'checklist', id: 'ch03', items: ['我能……'] }
  ]
});
```

支持的块类型：`h p callout code codegroup table term terms steps compare flow svg grid tabs checklist keypoint divider`。

其他数据文件：

- `data/quiz.js`：`CSC.registerQuizPack({ items: [...] })`，每题含 `id/ch/kp/type/stem/options/answer/explain`；
- `data/projects.js`：`CSC.registerProjects([...])`，每个项目含 `goals/milestones/starter/hints/solution/extension`；
- `data/exam.js`：`CSC.registerExam({...})`，每套卷含 `questions[].parts[]`（choice/tf/fill/output/keywords）。

改完直接刷新浏览器即可（http 方式下建议 Ctrl+F5 强刷）。

- **改配色 / 字号 / 线宽**：改 `assets/observatory.css` 顶部 `html[data-theme="dark"]` 里的 CSS 变量，全站生效。
- **改站点名称 / 启动日志 / 关于页**：改 `data/site.js`。

## 五、技术说明

- **无构建、无依赖、无 CDN**：全部原生 JS / CSS / SVG，字体本地打包，离线可用。
- **程序化视觉**：等高线地形由梯度噪声 + marching squares 生成（无贴图）；启动序列、打字机、四色幕布、四色色标均由 CSS/JS 实现。
- **代码高亮**：多语言词法高亮（Python / C / Shell），纯 JS 解析，不使用 `eval`。
- **判分**：选择题、判断题、填空题与读程序输出题在浏览器内自动判分；简答题按关键词给分并标注「人工对照」。
- **兼容**：Chrome / Edge / Firefox / Safari 近两年版本；桌面与移动端自适应（<900px 世界星图改纵向索引、侧栏变抽屉）；支持 `prefers-reduced-motion` 降级与打印。
- **数据与隐私**：成绩记录只存在浏览器 localStorage（`csc.c.*`），不上传任何服务器。

## 六、关于代码运行

本站是**阅读型**课程站：代码块只展示、不内置编译器。这样设计的理由是——

1. 真实学习必须自己把代码敲进本机、编译、看到真实报错与运行结果；
2. 网页内的迷你编译器/解释器容易让人误以为「看懂了」，而实际动手时会卡住。

建议工作流：点代码块右上角「复制」→ 在本地用 `gcc -std=c11 -Wall -Wextra` 编译运行 → 改一处再跑 → 关掉页面凭记忆重写。
