# 财务会计 · 学习站 · 使用说明

> 财务会计（Financial Accounting），按「章节 + 算例 + 自检」组织的一门完整学习站。
> 全站包含：8 章正文、速查表、分章题库（56 题）、模拟卷（12 题 / 100 分）、3 个实战项目与本地资料库。
> **纯静态、零安装、可离线**，双击 `index.html` 就能用。
>
> 视觉语言：NASA-Punk Observatory（深空天文台界面）——程序化等高线地形、Jura + Roboto Mono 仪表字体、四色色标、四色幕布转场。

---

## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。

**方法 2（可离线安装）**：在本文件夹里起一个静态服务器（任选一种）：

```powershell
python -m http.server 8790
```

```powershell
npx serve .
```

然后访问命令提示的地址（上面第一条是 `http://127.0.0.1:8790`）。用 http 打开后站点会注册 Service Worker，第一次加载完就能断网学习，也可以「安装到桌面」。

> 首页左上角的徽标可以随时点回观测台门户。

## 三、建议学习路径

1. **先读第 0 章**：用一章的篇幅建立「企业活动 → 三张报表」的整体地图，弄清八章各管什么。
2. **按 ch01 → ch07 顺序推进**：每章先看目标与知识地图，再精读正文与算例，最后做章节自检与题库。
3. **每章动手写一遍**：调整分录、试算平衡表、折旧表、现金流量表都不要只看，拿纸笔或表格算一遍。
4. **先做项目 P1，再做 P2、P3**：P1 走完整个会计循环；P2 比较政策对利润的影响；P3 用真实年报做分析。
5. **考前用模拟卷限时自测**：交卷后按解析归因，错题回到对应章节重读，而不是只背答案。

## 四、资料库说明

本站的资料库只有一组「教材全文」，指向同一份 PDF 的两个入口：

- `学习资料/ACT2111_Financial_Accounting_4th_Edition.pdf`

这是本站收到的唯一一份 ACT2111 课程文件，因此两个入口的路径相同，只是命名不同（通读入口 / 查章节入口）。资料库只保存相对路径，文件打包后在项目内 `resources/` 目录，未打包时为本机 `CUHKSZ course` 目录；正文、题库与项目不受影响。

## 五、数据与隐私

- 学习记录（读过的章、答过的题、项目进度）只存在浏览器 `localStorage`，**不上传任何服务器**。
- 清除浏览器站点数据会同时清除学习记录。
- 资料库里的链接指向原始资料文件：打包后在项目内 `resources/` 目录，未打包时为本机 `CUHKSZ course` 目录；正文不受影响。

## 六、常见问题

**Q：打开后页面空白？**
A：确认 `assets/` 与 `data/` 目录与 `index.html` 在同一层；不要只拷贝 `index.html` 一个文件。

**Q：题目答对没有加分？**
A：先交卷或点「查看解析」；单选与判断按精确匹配判分，填空按归一化文本判分，简答按关键词命中比例给分。

**Q：可以打印吗？**
A：可以。浏览器打印时会保留正文与表格；深色主题在纸上可能偏灰，建议打印前切换到浅色主题。

**Q：正文里的数字和教材不一致？**
A：本站算例多为演示数据，已在每章结尾的「覆盖范围与依据」中注明；以教材与课堂讲义为准。
