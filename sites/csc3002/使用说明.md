> C++ 程序设计（C++ Programming，CSC3002），按「章节 + 例子 + 自检」组织的一门完整学习站。
> 全站包含：8 章正文、5 页速查表、分章题库 56 题、100 分模拟卷、3 个实战项目与本地课程资料库。
> **纯静态、零安装、可离线**，双击 `index.html` 就能用。
>
> 视觉语言：NASA-Punk Observatory（深空天文台界面）——程序化等高线地形、Jura + Roboto Mono 仪表字体、四色色标、四色幕布转场。

## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。

**方法 2（可离线安装）**：在本文件夹里起一个静态服务器：

```powershell
python -m http.server 8790
```

然后访问 `http://127.0.0.1:8790`。用 http 打开后站点会注册 Service Worker，第一次加载完就能断网学习，也可以「安装到桌面」。

> 首页左上角的徽标可以随时点回观测台门户。

## 三、怎么用（推荐路径）

1. **先读 ch00**：十分钟看清这门课考什么、7 章怎么串、作业与考试的比重。
2. **按章顺序过正文**：每章开头有「为什么学这个」，中间是代码与对比表，末尾是自检清单。
3. **读完一章立刻做该章 7 道题**：错题会记录在本地，点「只看错题」可以二刷。
4. **每两章做一次速查表复习**：速查表按「概念 / 语法 / 坑」三列组织，适合考前 20 分钟扫一遍。
5. **三个项目按难度递进做**：P1 只依赖 ch01 与 ch06，P2 需要 ch03/ch05/ch07，P3 综合 ch04/ch06/ch07。每个里程碑都给了 starter 与 solution，建议先自己写再看答案。
6. **最后做模拟卷**：90 分钟闭卷，做完对照评分要点，把丢分点回到对应章节。

> 所有 C++ 代码示例都在 `g++ -std=c++17 -Wall -Wextra` 下验证过；涉及内存的示例建议加 `-fsanitize=address,undefined` 再跑一遍。

## 四、数据与隐私

- 学习记录（读过的章、答过的题、项目进度）只存在浏览器 `localStorage`，**不上传任何服务器**。
- 清除浏览器站点数据会同时清除学习记录。

## 六、常见问题

**Q：打开是白屏？**
浏览器直接打开 `file://` 时，个别浏览器会拦截 ES module 之外的本地请求。换 Chrome / Edge，或用上面的 `http.server` 方法。

**Q：改完 `data/*.js` 页面没变化？**
Service Worker 会缓存旧版本。按 `Ctrl+Shift+R` 强制刷新；或在 DevTools → Application → Service Workers 里点 Unregister 再刷新。

**Q：题库答案能改吗？**
可以。`data/quiz.js` 里每题有 `explain`，改答案时同步改解析，避免出现「答案 A、解析说 B」的情况。

**Q：资料库链接点了没反应？**
确认项目内 `resources/CSC3002/`（已打包）或同级 `CUHKSZ course/CSC3002/`（未打包）目录还在；链接是相对站点目录的，移动资料目录会导致 404。

**Q：能打印吗？**
可以。正文与速查表都做了打印样式，浏览器「打印 → 另存为 PDF」即可，表格不会被截断。
