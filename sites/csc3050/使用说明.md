> CSC3050 Computer Organization and Systems Programming 的本地学习站：把「数据怎么表示 → 指令怎么执行 → 流水线怎么重叠 → 存储怎么分层 → 程序怎么被链接加载 → 性能怎么度量」串成一条线。
> 全站包含 **8 章正文、56 道分章练习题、一份 100 分模拟卷、4 个实战项目、4 页速查表、6 组本地资料索引**。

## 一、怎么打开

**方法 1（最简单）**：双击 `sites/csc3050/index.html`，用 Chrome / Edge / Firefox / Safari 打开。

**方法 2（可离线安装）**：在本文件夹里起一个静态服务器：


然后访问 `http://127.0.0.1:8790`。用 http 打开后站点会注册 Service Worker，第一次加载完就能断网学习，也可以「安装到桌面」。

## 二、这门课在讲什么

CSC3050 的主线只有一句话：**高级语言写的程序，如何一步步变成硅片上的电信号，又为什么快不起来。**

课程按四部分展开，本站的八章与之一一对应：

| 部分 | 章节 | 核心问题 |
| --- | --- | --- |
| Part I · 导览 | ch00 课程地图 | 一台计算机有哪些抽象层？这门课在整张地图的哪个位置？ |
| Part II · 基础 | ch01 数制与数据表示 | 同样的 32 个 0/1，为什么能表示整数、浮点、指令和字符串？ |
| Part II · 基础 | ch02 RISC-V 指令系统与调用约定 | 一条 C 语句被翻译成哪些指令？函数调用时栈上发生了什么？ |
| Part III · 深入 | ch03 处理器数据通路 | 一条指令如何走过取指、译码、执行、访存、写回？ |
| Part III · 深入 | ch04 流水线与冒险 | 五条指令重叠执行时，冲突从哪里来、怎样消除？ |
| Part III · 深入 | ch05 存储层次与 Cache | 为什么程序「看起来」比内存快得多？局部性如何被硬件利用？ |
| Part IV · 综合 | ch06 链接与加载 | 从 `.c` 到进程，符号、重定位、动态库各做了什么？ |
| Part IV · 综合 | ch07 性能与并行 | 怎样用 CPI、Amdahl 与 roofline 判断优化是否值得？ |

课程使用的教材是 Patterson & Hennessy《Computer Organization and Design》RISC-V Edition，参考书是 CS:APP。课件里出现的 RV32I、五级流水、直接映射 Cache、ELF 与动态链接，本站都按同一口径讲解，例子可以手算复现。

**考核结构**（来自课程组织课件）：出勤 5% + 随堂测验 25% + 四个 Project 45% + 开卷期末 25%。Project 分别是汇编 10%、Bomb Lab 10%、流水线模拟器 12.5%、Cache 模拟器 12.5%。期末可带教材与纸质笔记，不可使用电子设备——所以平时要练「合上书也能推」。

## 三、八章怎么读

每一章都按同一节奏组织，可以按顺序读，也可以按需跳读：

1. **开头的「为什么」**：先给一个具体现象或反例，说明这一章要解决什么问题。
2. **正文小节**：概念 → 例子 → 手算 → 常见错误。出现的数字（位模式、周期数、缺失率）都可以自己验算。
3. **表格与对比**：把容易混的两三个概念并排放，例如补码 vs 反码、单周期 vs 流水线、直接映射 vs 组相联。
4. **代码块**：C 与 RV32 汇编对照，重点是「这段 C 被翻译成了什么」，不是背指令表。
5. **自测题**：每章 2–3 道内嵌小题，做完立刻看解析；完整题库在「题库」页。
6. **小结与自检清单**：合上页面，能逐条说清才算过。

建议的读法：

- **第一遍**（每章 60–90 分钟）：只求主线，遇到公式先跳过大推导，把例子跟着算一遍。
- **第二遍**（每章 30 分钟）：回看自检清单，把说不清的点记下来，去题库做对应章节。
- **考前**：只看速查表 + 错题 + 模拟卷，不再从头读正文。

时间紧的话，优先顺序是 ch02（指令与调用约定）→ ch04（流水线与冒险）→ ch05（Cache）→ ch01（数据表示）。这四块占了期末计算题的大头，也是四个 Project 的共同基础。

## 四、题库、模拟卷与速查表

### 题库（56 题）

- 每章 7 题，覆盖单选、多选、判断、填空、读代码/写结果五种题型。
- 题目按难度分三档：`基础` 是概念辨析，`进阶` 要算一步，`挑战` 需要把两章知识接起来。
- 答完立即判分并展开解析；解析里会指出「错选通常意味着哪个概念没转过来」。
- 填空题对大小写与空格做了归一化，`0x2A` 与 `0x2a`、`42` 与 `42 ` 都算对；写结果题按行比对。
- 判断题不要只看结论，解析里的反例才是重点。

### 模拟卷（12 题 / 100 分 / 90 分钟）

- 题型与分值对齐期末：选择 2 题 16 分、判断 2 题 16 分、填空 2 题 16 分、计算与写结果 4 题 36 分、简答 2 题 16 分。
- 计时从点「开始」起算，刷新页面不会暂停；交卷后按题型自动判分，简答题按关键词命中比例给分。
- 简答题没有唯一表述，命中要点即可；对照解析时重点看「自己的答案缺了哪一层理由」。
- 建议用法：第一遍闭卷限时，第二遍开卷只做错题，第三遍只看解析里的公式与易错点。

### 速查表（4 页）

- **数据表示**：进制转换、补码、符号扩展、IEEE 754 拆位、溢出判定。
- **指令与调用**：六种指令格式、常用指令语义、栈帧布局、caller/callee 分工。
- **流水线与 Cache**：五级结构、冒险类型与解法、地址拆分公式、AMAT 与 3C。
- **链接与性能**：ELF 节、重定位类型、静态/动态库、CPU 时间、CPI、Amdahl。
- 每页都是「考前一小时能看完」的密度，适合打印或放在第二块屏幕。

## 七、学习建议与常见问题

**Q：汇编需要背指令表吗？**
不需要背全表，但要熟到「看到 `lw x5, 8(sp)` 能立刻说出它在干什么」。常考的十几条（add/addi/lw/sw/beq/bne/jal/jalr/lui/auipc/slli/srai）必须条件反射，其余可以查。

**Q：流水线周期数总算是多算一拍或少算一拍？**
先画时空图，再数「最后一条指令的 WB 落在第几拍」。记住三个基准：无冒险 N 条指令约 N+4 拍；load-use 多 1 拍；EX 判定分支失败多 2 拍、MEM 判定多 3 拍。

**Q：Cache 题为什么总在 tag 位数上出错？**
因为忘了先算「行数」再算「组数」。直接映射行数=组数；K 路组相联组数=行数/K。地址拆分永远是 `tag | index | offset`，从低位往高位切。

**Q：链接错误 `undefined reference` 怎么查？**
先确认符号有没有定义（`nm`），再确认目标文件/库有没有出现在链接命令行，最后确认库的顺序（依赖者在前）与 C++ 的 `extern "C"`。

**Q：模拟卷做不完怎么办？**
按分值分配时间：16 分的选择判断控制在 15 分钟，36 分计算留 40 分钟，16 分简答留 20 分钟，剩下 15 分钟检查。计算题写公式就有过程分，不要空着。
