# 线性代数学习站 · 使用说明

> **LINEAR ALGEBRA OBSERVATORY** —— 给第一次学线性代数的人看的教材。
>
> 内容依据 Gilbert Strang《Introduction to Linear Algebra》第 5 版（Wellesley-Cambridge, 2016）的全书结构编排：
> 向量与 `Ax=b` → 子空间与正交 → 特征值与 SVD → 复数、应用与数值。
> **纯静态、零安装、可离线**，打开就能从第一页读起。
>
> 视觉采用 **NASA-Punk Observatory** 设计语言（参考 flowersauce/NASA-Punk_Observatory，MIT）：
> 深空天文台界面 —— 程序化等高线地形、Jura + Roboto Mono 仪表字体、四色色标、终端读数、四色幕布转场。
> 界面好看是加分项，真正要看的还是每一章里的文字和公式。

## 一、怎么打开

**方法 1（最简单）**：双击文件夹里的 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。
所有章节、公式、实验台、题库都在本地文件里，不需要联网、不需要装任何东西。

**方法 2（推荐，可离线安装）**：在本文件夹里起一个静态服务器，浏览器访问 `http://127.0.0.1:8789`：

```powershell
# 在本文件夹内执行（Python 3；本机用 py 而不是 python）
py -m http.server 8789
```

用 http 打开后，站点会注册 Service Worker——第一次加载完，**断网也能继续学**，
还可以在浏览器里「安装到桌面」，像 App 一样用。

> 首页左上角的徽标可以随时点回初始页（世界星图入口）。
>
> **默认显示比例 115%**：桌面端整站按 115% 显示（正文、读数、公式一起放大，
> 默认阅读更舒服）。想改回原始大小或再放大，编辑 `../../shared/css/observatory.css` 顶部那一行
> `html[data-skin="obs"] { --ui-zoom: 1.15; }`（1.0 = 原样，1.25 = 再大一档）；
> 手机端不使用该缩放（交给浏览器自己的视口）。

## 二、这是一本什么样的教材

一本把 **Strang 5e 全书**（12 章 + 矩阵分解附录 + 公式速查）拆成 **15 个学习模块**的
交互式教材，按 **4 个 Part** 组织：

| Part | 主题 | 模块 |
| --- | --- | --- |
| I | 向量的语言 | 00 总览与学习路线 · 01 向量导论 · 02 解线性方程组 |
| II | 子空间与正交 | 03 向量空间与子空间 · 04 正交性 · 05 行列式 |
| III | 特征与分解 | 06 特征值与特征向量 · 07 奇异值分解 · 08 线性变换 |
| IV | 复数、应用与数值 | 09 复向量与复矩阵 · 10 应用 · 11 数值线性代数 · 12 概率统计中的线性代数 · 附录 · 公式速查 |

每一章都从「这一章要解决什么问题」讲起：先给直觉和例子，再写定义和公式，最后用例题、实验台和练习题把话讲通。
全书有两条主线：**四个基本子空间**（列空间、零空间、行空间、左零空间）与 **矩阵即线性变换**。

如果只记住一句话：**这里假设你还没学过线性代数**。看到看不懂的符号，往回翻或查术语表，不用假装自己已经会了。

## 四、想自己改内容？

正文是**数据驱动**的：每章一个 `data/chXX.js`，文件结构如下（完整字段见各数据文件的字段注释）：

```js
CSC.registerChapter({
  id: 'ch05', num: '05', title: '行列式', en: 'Determinants',
  goals: ['……'],                          // 学完这一章你能做什么
  kp: [{ id:'ch05-s1', title:'2×2 行列式与平行四边形的面积' }], // 知识点
  blocks: [                               // 内容块，按顺序渲染
    { t: 'scope', scope:'core', weeks:'第 7 周', sections:'§5.1–5.3' },  // 模块范围横幅
    { t: 'h', lvl: 2, text: '这一章要解决什么问题' },
    { t: 'list', items: ['一条要点，可以用 <code>行内代码</code> 和 $公式$'] },
    { t: 'tex', tex: '\\det(A)=\\begin{vmatrix}a&b\\\\c&d\\end{vmatrix}' },  // 独立公式纸片
    { t: 'theorem', name: 'det 与可逆', zh: '行列式与可逆', rows: [{ k:'白话', html:'…' }, { k:'条件', html:'…' }, { k:'结论', html:'…' }] },
    { t: 'example', no: '1', tag: '跟着做一遍', fields: [{ k:'题目', html:'…' }, { k:'思路', html:'…' }, { k:'解答', html:'…' }, { k:'点评', html:'…' }] },
    { t: 'lab', id: 'determinant' },
    { t: 'quiz', qid: 'ch05-q1' },
    { t: 'checklist', id: 'ch05', items: ['能自己讲出来吗：……'] }
  ]
});
```

支持的块类型：`h p list tex example theorem formula scope callout table term terms lab quiz steps compare flow svg grid tabs checklist keypoint divider html`。

> 数学源码约定：**LaTeX 命令在 JS 字符串里写两个反斜杠**（磁盘上 `\\det`、`\\begin{bmatrix}`），
> 小于号大于号用 `\\lt` / `\\gt`（HTML 里用 `&lt;` / `&gt;`）；其余约定见 `data/` 各文件的注释。

改完直接刷新浏览器即可（http 方式下建议 Ctrl+F5 强刷）。

- **改配色 / 字号 / 线宽**：改 `../../shared/css/observatory.css` 顶部 `html[data-theme="dark"]` 里的 CSS 变量即可，全站生效。
- **改页面布局**：外壳与首页在 `../../shared/css/observatory.css`，数学内容在 `assets/math.css`，其余页面在 `../../shared/css/pages-*.css`（六站共享一份，改前留意会影响所有站）。
- **改视觉组件参数**（等高线密度、启动文案时长）：调用 `CSC_OBS.mountTopo / mountBoot` 时传参，见 `assets/observatory.js` 文件头注释。
- **改题库**：`data/quiz.js`，每题 `{ id, ch, type:'mcq', difficulty, tags, stem, options:[{text,correct}], explain }`。
- **改模块顺序 / 标题**：`data/index.js`；首页星图、侧栏、航线图、搜索都会跟着变（但世界风格映射在 `assets/app.js` 的 `WORLD_MAP`，按数组下标对应，改顺序时要一起改）。

## 五、技术说明

- **无构建、无依赖、无 CDN**：全部原生 JS / CSS / SVG，字体与 MathJax 本地打包，离线可用。
- **公式排版**（`assets/math.js`）：**首次进入含公式的章节时按需注入 MathJax**（首页 / 总览不加载），
  就绪后统一排版，并对每个公式做四层适配——
  ① 过宽行内公式提升为独立「公式纸片」；② 仍放不下按顶层 `=` / `\qquad` 拆成 `aligned` 多行；
  ③ 拆不了（矩阵、分段等）等比缩小（下限 62%，表格内 85%）；④ 表格窄屏转一列卡片。
  缩放后仍超宽的公式与长表格会加上「← 可横向滚动 →」提示与右侧渐隐遮罩，避免无提示地裁切核心内容。
- **数据按需加载**：章节正文、题库、模拟卷、实验台、术语表、公式速查都只在点开对应页面时加载；
  首屏关键路径是 `index.html + data/site.js + CSS + observatory.js + app.js + math.js`，MathJax 不在首屏加载。
- **程序化视觉**：等高线地形由梯度噪声 + marching squares 生成（无贴图）；启动终端、打字机、四色幕布均由 CSS/JS 实现。
- **安全**：不使用 `eval`/`new Function` 执行内容；公式只经 MathJax 排版。
- **兼容**：Chrome / Edge / Firefox / Safari 近两年版本；桌面与移动端自适应（<900px 世界星图改纵向模块索引）；
  支持 `prefers-reduced-motion` 降级与打印。

### 数学公式排版规则

1. 行内公式超过栏宽约 62% 时，自动变成一张居中「公式纸片」，不再和汉字挤在同一行。
2. 独立公式仍放不下时，按**顶层等号**和 `\qquad` 拆成多行（保持原字号）。
3. 既拆不了又放不下的，等比缩小字号（下限 62%，表格内 85%）。
4. 表格在窄屏（≤700px）自动变成「一列卡片」，每格带表头标签。
5. 缩放后仍超出容器的公式与长表格，会出现「← 可横向滚动 →」提示与右侧渐隐，可以横向拖动查看完整内容。
